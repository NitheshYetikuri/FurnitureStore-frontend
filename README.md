# FurnitureStore Frontend

## Description
The `FurnitureStore-frontend` is an Angular-based frontend application for an e-commerce furniture store. This project provides a user-friendly interface for customers to browse and purchase furniture items.

## Features
- **Angular Framework**: Utilizes Angular for building a dynamic and responsive user interface.
- **User Authentication**: Supports user login and registration.
- **Product Management**: Allows users to view, search, and filter furniture items.
- **Shopping Cart**: Enables users to add items to the cart and proceed to checkout.
- **Order Management**: Provides order history and tracking for users.

## Installation
To set up the project locally, follow these steps:

1. **Clone the repository**:
   ```sh
   git clone https://github.com/NitheshYetikuri/FurnitureStore-frontend.git
   cd FurnitureStore-frontend
   ```

2. **Install dependencies**:
   ```sh
   npm install
   ```

3. **Run the application**:
   ```sh
   ng serve
   or
   npm run
   ```

4. **Access the application**:
   Open your browser and navigate to `http://localhost:4200`.

## Backend
For the backend of this application, please check the FurnitureStore-backend repository, which is built using Java and Spring Boot.
